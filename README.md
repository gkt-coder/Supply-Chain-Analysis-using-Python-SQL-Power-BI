# Supply Chain Analysis Using Python, SQL & Power BI

## Project Overview
An end-to-end Data Analytics project focused on analyzing supply chain and warehouse operations to support data-driven business decisions.

The project covers data cleaning, preprocessing, feature engineering, SQL-based business analysis, and an interactive Power BI dashboard.

## Business Problems
- Delivery delays
- Inventory imbalance
- High operational costs
- Demand and stock mismatch
- Warehouse performance monitoring
- Employee/workforce gaps
- Slow decision-making from scattered data

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- MySQL / SQL
- Power BI
- Excel
- Visual Studio Code
- MySQL Workbench

## Dataset
- Domain: Logistics & Supply Chain Management
- Records: 500
- Features: 30 columns
- Format: CSV

## Python Analysis
Data cleaning, preprocessing, and feature engineering were performed using Python.

Key business metrics created include:
- Required Employees
- Employee Gap
- Need Employee Shifting
- Total Cost
- Cost Per Sale
- Revenue
- Profit
- Inventory Gap
- Optimized Stock
- Order Delay

## SQL Analysis
SQL was used to analyze:
1. Top delayed warehouses
2. High stockout-risk locations
3. Product category sales performance
4. Cost vs. profit
5. Demand vs. stock comparison

## Power BI Dashboard
The interactive dashboard monitors:
- Sales
- Revenue
- Profit
- Total Cost
- Inventory
- Warehouse Performance
- Employee Utilization
- Delivery Performance
- Customer Rating

### Dashboard KPIs
- Total Sales: 2.78M
- Total Revenue: 40.3M

## Key Insights
- Identified inventory shortages and overstock situations using Inventory Gap analysis.
- Analyzed warehouse performance and stockout risk.
- Compared revenue, cost, and profit to evaluate warehouse profitability.
- Identified employee shortages and workforce gaps.
- Analyzed delivery delays and potential bottlenecks.
- Built an interactive dashboard to support business decision-making.
